# Analytical Outputs and Visualizations (`outputs/`)

This directory houses the figures, summary tables, and trained model artifacts generated by the HiddenCare analytical pipeline.

## Directory Structure

* **`figures/`:** Publication-grade visualizations and clinical charts.
* **`tables/`:** CSV tables summarizing sample attrition, screening metrics, complex survey variance, and subgroup equity audits.
* **`models/`:** Serialized gradient-boosted model files (excluded from git via `.gitignore`).

## Deliverables Summary

### 1. Figures (`outputs/figures/`)

| File | Description |
| :--- | :--- |
| `capacity_tradeoff.png` | Cumulative yield and Number Needed to Screen (NNS) across 5% to 50% capacity constraints |
| `paired_overlap_20pct.png` | Distribution of the 61 patients who swap priority ranking at the 20% budget line |
| `robustness_comparison.png` | Performance comparison across Gradient Boosting and Random Forest architectures |
| `subgroup_audit_insurance.png` | Disaggregated sensitivity audit comparing insured vs uninsured individuals |
| `subgroup_audit_income.png` | Sensitivity audit evaluated across Poverty Income Ratio (PIR) brackets |

### 2. Tables (`outputs/tables/`)

| File | Description |
| :--- | :--- |
| `cohort_flow.csv` | Sequential participant attrition table documenting each exclusion step |
| `metrics_summary.csv` | Full screening performance comparison (sensitivity, specificity, NNS, cases found) |
| `paired_overlap_20pct.csv` | Patient overlap and swap summary at the primary 20% screening threshold |
| `survey_variance_summary.csv` | CDC/NCHS Taylor Series Linearization standard errors and 95% confidence intervals |
| `robustness_model_comparison.csv` | Metric comparison confirming findings hold across tree architectures |
| `subgroup_audit_20pct.csv` | Demographic and socioeconomic subgroup sensitivity audit |
| `random_baseline_summary.csv` | Baseline screening performance under unguided random selection |
| `tuning_summary.csv` | Hyperparameter search logs and validation scores |
